모니터 설정 SNMP 도움말

그림·인쇄본은 저장소 doc/사용설명서/manual/사용설명서.html 을 보십시오.

1. 7인치 화면

전원을 켜면 메인 화면에 팩 전압·셀·온도가 나옵니다. 값은 약 2초마다 갱신됩니다. 오른쪽 #1 / #2로 팩을 고릅니다. 설 정에서 IP·장치 이름을 바꿉니다. 하단 STATUS 는 STATUS:#n 정상 / 통신끊김 / 경보#n 입니다.

2. IP Finder (PC)

실행 파일 python/release/IPFinder.exe (또는 python/SnmpFinder.py). 같은 LAN에서 UDP 1234로 장비를 찾고 IP·서브넷·게이트웨이·WEB ENABLE·WEB PORT 를 바꿉니다. 적용 후 재부팅합니다. NOTE 열에는 장치 이름(기본 BAT RACK1)이 보입니다. Finder의 TRAP 칸은 공통 도구입니다. 이 제품은 SNMP TRAP을 보내지 않습니다.

3. 웹 화면

주소 http://장비IP:포트 (공장 192.168.0.57:81). 로그인 기본값 admin / admin. 상단 메뉴: 모니터 · 설정 · SNMP · 도움말 · 업로드.

4. 펌웨어 업데이트

펌웨어는 앱 BLE → 재부팅 → Wi‑Fi OTA 입니다. 유선 이더넷으로는 .bin 을 올리지 않습니다. 앱: IFTECH_SAMWOO_App/release/IFTECH_SAMWOO_App.apk 연결 → IFTECH_SW_ SCAN → SSID/PASS 전송 → update → 재접속 version.
