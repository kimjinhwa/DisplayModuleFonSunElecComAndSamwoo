# 삼우 리튬 BMS 디스플레이 사용자 매뉴얼

인쇄·화면용 본문은 아래 HTML입니다. Chrome에서 열거나 PDF로 출력합니다.

**[doc/사용설명서/manual/사용설명서.html](../doc/사용설명서/manual/사용설명서.html)**

같은 폴더:

| 파일 | 용도 |
|------|------|
| `사용설명서.html` | 화면 열람 + 인쇄 |
| `make_pdf.ps1` | Chrome/Edge 헤드리스 → `사용설명서.pdf` |
| `capture_shots.py` | 장비 웹 화면 캡처 |
| `capture_finder.ps1` | IP Finder 창 캡처 |
| `img/` | 그림 |

```
cd doc\사용설명서\manual
powershell -ExecutionPolicy Bypass -File .\make_pdf.ps1
```

장비 웹의 **도움말**은 그림 없는 요약입니다. 그림이 필요하면 위 HTML을 여십시오.
